# Security policy

fair.yoga holds personal data about yoga teachers and their students, so we take
reports seriously and we're grateful for them.

## Reporting a vulnerability

**Please don't open a public issue.** Report it privately instead:

- **Preferred:** [GitHub private vulnerability reporting](https://github.com/ivohofland/fair.yoga/security/advisories/new)
- **Or email:** hello@fair.yoga, starting the subject with `Security:`

Helpful to include: what an attacker could do, the steps to reproduce it, and the
commit or page you tested against. Please don't access, change or delete data that
isn't yours while investigating.

## What to expect

fair.yoga is built by volunteers, so we can't promise a fixed response time. We will
acknowledge your report, keep you updated while we work on it, and credit you in the
advisory if you'd like.

## Supported versions

Only the latest `main` is supported.
